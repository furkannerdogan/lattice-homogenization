How to read this

nt is the number of elements across the thinnest wall; the element size there is h = tmin/nt. Every other size in the mesh (grading away from walls, the cap in the interior) is a fixed multiple of h, so halving h refines the whole mesh in proportion.

Observed order p. If the error behaves like a hp, three meshes with ratios r21 = h2/h1, r32 = h3/h2 determine p (Celik et al. 2008, fixed-point form for unequal ratios).

Richardson extrapolation estimates the value at h → 0: fext = (r21p f1 − f2) / (r21p − 1).

GCI (Roache 1998) is an error band on the finest mesh with safety factor Fs = 1.25: GCI = Fs |f1 − f2|/|f1| / (r21p − 1). It is meaningful only in the asymptotic range, where the error behaves like a hp. The table checks this by comparing p from the three finest meshes with p from the next coarser triple: similar values mean asymptotic.

Corners. Where walls meet at a re-entrant corner the elastic stress is singular (σ ~ rλ−1, 0 < λ < 1): the peak stress keeps growing with refinement and never converges. Cij is a strain energy, an integral over the cell, and stays finite, so it converges, at an order set partly by the corner angle. Oscillatory convergence (sign changes between levels) makes p unreliable; the table flags it.
